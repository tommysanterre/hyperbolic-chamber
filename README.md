# SnackLoop

SnackLoop is a tiny offline-first Android app for moving through a continuous rotation of movement snacks.

## Rotation

1. Push-ups — 5–10 reps
2. Squats — 10–15 reps
3. Deep squat hold — 30 sec
4. Pull-ups — 2–5 reps
5. Dead hang — 30 sec
6. Reverse lunges — 5 per side
7. Hip-flexor stretch — 30 sec per side

Complete the movement shown, record the amount, and SnackLoop advances to the next movement. The queue persists across days. There is no skip action or daily limit.

## Build

Pushes to `main` build a debug APK with GitHub Actions. Download the `SnackLoop-debug` artifact from the latest successful Actions run and install the APK on Android.
