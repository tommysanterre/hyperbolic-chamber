# Equipment Inventory

Reference inventory for adapting workouts and daily snack routines. Keep this file updated whenever equipment is acquired, sold/discarded, or setup preferences change. New equipment can always be recommended when there is a strong reason for a goal, progression gap, or pain-free adaptation (keep unowned suggestions separate from Owned gear).

## Training Context

- **Primary goal:** Living pain-free, functional strength, and general fitness
- **Schedule:** Strict 3 × 30 min dedicated workouts/week (2× full-body strength + 1× cardio) plus light daily mobility/movement snacks
- **Surface:** Interlocking EVA foam tiles (keep freestanding gear loaded vertically so feet stay planted and do not slide)
